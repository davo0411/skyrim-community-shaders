# Attribution

The rules in `design-principles.md`, `audit-checklist.md`, `critique-rubric.md`, `pretty-ui-checklist.md` and `DESIGN.md` are adapted from the projects below, paraphrased and translated from web UI to Dear ImGui and the Community Shaders design system. Nothing is copied verbatim beyond short rule names. Changes made: web-only rules dropped or translated, thresholds mapped to `ThemeManager::Constants`, examples rewritten for CS.
